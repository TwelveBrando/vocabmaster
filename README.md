# VocabMaster AI — Desktop Vocabulary Trainer

Десктопное приложение для эффективного тестирования и расширения словарного запаса с поддержкой ИИ (Google Gemini / Groq / OpenRouter) и 100% клавиатурным управлением.

---

## 🚀 Быстрый запуск

В папке `C:\TestVocabulary`:

```bash
# Запуск приложения в режиме разработки (Vite + Electron)
npm run dev
```

Или для запуска веб-версии в браузере:
```bash
npm run dev:vite
```

---

## 🎯 Реализованный функционал

1. **Ввод слов через запятую**:
   - Поддерживает одиночные слова, фразовые глаголы и идиомы (например: `prescription, chore, appearance, apologize, succeed, look forward to, niece, blanket, find out, break down, relieved, put on, curly, bring up...`).
   - Кнопка «Вставить пример» для моментального тестирования.
   - Автоматическая очистка и подсчет уникальных слов.

2. **3 формата тестирования**:
   - **Формат 1 (Выбор варианта):** Выбор перевода из 2–7 вариантов ответа (количество настраивается пользователем). ИИ генерирует правдоподобные варианты ответов (дистракторы).
   - **Формат 2 (Русский → English с контекстом от ИИ):** На экране русское слово с детальной контекстной подсказкой от ИИ (например: *«поднимать (руку/цену)»* или *«через (сквозь: сквозь лес/стену)»*), чтобы избежать путаницы между синонимами. Ввод на английском языке.
   - **Формат 3 (English → Русский):** На экране английское слово. Ввод перевода на русском языке.

3. **100% Keyboard-Driven UX (без мыши)**:
   - Автоматический непрерывный фокус на поле ввода.
   - `Enter` — подтверждение ответа и переход к следующему слову.
   - Цифры `1`..`7` (в Формате 1) — мгновенный выбор варианта ответа.
   - `Esc` — выход в главное меню.
   - `Ctrl + Enter` — быстрый запуск теста с экрана настройки.
   - `R` (на экране результатов) — повторить тест только по допущенным ошибкам.

4. **Интеграция с ИИ и локальный кэш**:
   - По умолчанию используется **Google Gemini 3.5 Flash-Lite** (free tier, быстрый строгий JSON-ответ), также поддерживаются **Groq Cloud** и **OpenRouter**.
   - Встроенная база для популярных слов (работает сразу даже без API-ключа).
   - Локальный кэш: изученные слова сохраняются и не запрашиваются повторно у ИИ.

5. **Звуковые эффекты & Анимации**:
   - Синтезированные звуки успеха и ошибок через Web Audio API (без внешних аудиофайлов).
   - Анимация конфетти при успешном завершении теста.
